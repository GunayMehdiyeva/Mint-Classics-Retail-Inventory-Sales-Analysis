# This project analyzes a multi-table relational database for Mint Classics, a fictional retailer of classic model cars, to support data-driven inventory and warehouse decisions.
Mint Classics is a fictional company selling classic model cars. The business question was whether its warehouse operations could be optimized, including whether closing or downsizing a warehouse might be feasible without negatively affecting customer service.

Tools: MySQL Workbench, SQL, Power BI, DAX

Business analysis · Dashboard development · Inventory optimization
